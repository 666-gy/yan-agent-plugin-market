# Wallpaper Engine 壁纸桥接 · 新手教程（市场核心版）

这份教程在插件包的 `TUTORIAL.md`；安装后也可以在 **Yan 插件页 → 插件详情 →「新手教程」** 打开。完整参数见 `README.md`。

> 市场核心版不修改 Yan 的 `app.asar`，没有「设置 → 壁纸」里的 WE 面板；使用浏览器自选面板即可。设置页 WE 面板在单独的完整版中。

## 0. 这个插件做什么

把本机 **Wallpaper Engine** 的壁纸导入 **Yan 窗口内**，作为 Yan 的界面壁纸。

- 不改 Windows 桌面壁纸。
- Wallpaper Engine 不需要开着；插件直接读壁纸文件。
- 视频会转成壁纸安全规格；场景类只能导入静态图。

## 1. 安装

1. 在 Yan 的插件安装入口（插件页 /「插件与智能体」）选择包含 `yan-plugin.json` 的插件目录。
2. 启用插件。
3. 重启/刷新 Yan，让 MCP 工具加载。

要求：Windows + Wallpaper Engine（Steam 431960）+ 至少一个订阅/本地壁纸。

## 2. 第一次检查

对 Yan 说：

> 检查 WE 壁纸环境

正常结果：

- `steamLibraries`：Steam 库路径
- `workshopWallpapers`：创意工坊壁纸数量（大于 0）
- `ffmpeg.available`：是否找到 ffmpeg（可选）

如果是 0：

- 确认 WE 已安装、创意工坊壁纸已订阅并下载完成。
- Steam 是绿色版/非标准路径时，在插件配置填 `steamLibrary`（如 `D:\Steam`），再检查。
- 本地项目会从 `wallpaper_engine/projects/myprojects` 读取。

## 3. 打开浏览器自选面板（浏览器是怎么启动的）

对 Yan 说：

> 打开壁纸自选面板

背后流程：

1. 插件启动本地零依赖 HTTP 服务 `gallery.cjs`，只绑定 `127.0.0.1:43197`。
2. 服务提供页面 `/` 和接口 `/api/list`、`/api/import` 等。
3. 插件用 Windows 默认浏览器打开 `http://127.0.0.1:43197`。
4. 面板 30 分钟无操作自动关闭；再次打开会重新启动。

浏览器没自动弹出时：

- 确认已经执行过「打开壁纸自选面板」，然后手动访问 `http://127.0.0.1:43197`。
- 这个地址只在本地后端运行时有效。
- 端口被占用时在插件配置改 `galleryPort`，再重新打开面板。
- 本地页面，不走互联网；不需要 WE 开着。

## 4. 浏览、导入、应用

- 卡片墙显示创意工坊和本地项目壁纸，支持搜索、类型过滤。
- `video 动态`：会动的视频壁纸。
- `scene / web / application 静态`：只能导入一张高清静图，不会动。
- 「导入并应用」：导入并设为当前 Yan 壁纸。
- 「仅入库」：只加入 Yan 壁纸库，不切换。
- 顶部「已导入」区域可以移除、移除并删文件、一键修复视频兼容性。

导入后：

- 浏览器面板导入：打开 Yan 设置页或重启后生效。
- 视频超过 50MB 或编码不兼容：有 ffmpeg 自动转码；没有 ffmpeg 会尽量用静态备用图。

## 5. 常见问题

- **扫到 0 个壁纸**：WE 没安装/没订阅下载，或 Steam 路径非标准；填 `steamLibrary`。
- **视频黑屏/卡顿**：先「一键修复视频兼容性」；没有 ffmpeg 就安装 ffmpeg，或换小一点的视频。
- **场景壁纸不动**：`scene / web / application` 只能静态图；要动态请选 `video`。
- **浏览器打不开**：确认后端已启动，手动访问 `http://127.0.0.1:43197`；检查端口占用。
- **想在设置页看到 WE 面板**：市场核心版不包含；使用单独的完整版（GitHub Release）。
- **想还原 Yan**：市场核心版没有改 `app.asar`，无需还原。

## 6. 卸载

- 在 Yan 插件页停用/卸载插件。
- 已导入的 Yan 壁纸可以在 Yan 设置 → 壁纸里删除，或调用 `we_list_imported` / `we_remove_imported`。
